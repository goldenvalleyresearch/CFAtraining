Daily Returns

Time-weighted: each day's gain is measured against the prior day's balance and the days are chained together, so the timing of contributions doesn't affect the result. This is how funds and indexes report returns. Benchmarks show the ETF's own return from its opening price on the start date.

Simple: total gain divided by total money put in. Benchmarks show what the same money would have returned in each ETF: the starting capital bought at the open on the start date, and each contribution bought at the close on the day it arrived.

In both methods contributions are never counted as gains. Benchmarks include dividends. Benchmark prices: Yahoo Finance. Account data: Fidelity.
